🍋 ***Little Lemon — Installation Guide***


Before installing the project, make sure the following tools are installed on your computer:

## Prerequisites

| Tool | Minimum Version | Download |
|------|----------------|----------|
| Node.js | v18.0+ | https://nodejs.org |
| npm | v9.0+ | Included with Node.js |
| Git | v2.40+ | https://git-scm.com |
| Expo Go | Latest Version | App Store / Google Play |
| VS Code (Recommended) | Latest Version | https://code.visualstudio.com |


### Step-by-Step Installation

***Step 1 — Clone the Repository***
Open a terminal and run the following command:

git clone https://github.com/susanavg04/little-lemon.git
cd little-lemon

***Step 2 — Install Dependencies***
Install all required packages defined in package.json:

npm install

This process may take a few minutes depending on your internet connection.

***Step 3 — Start the Development Server***

Run Expo to compile and serve the application:

npx expo start

***Step 4 — Open the Application***

Once the server is running, you have multiple options:

Physical Device

Scan the QR code using the Expo Go app.

Android Emulator

Press: a

iOS Simulator (macOS only)

Press: i
